# Garmin Insights Launch Instructions

This project is a Streamlit dashboard for Garmin Connect data. It can sync your Garmin data into a local SQLite database, then show trends, activity history, and optional AI insights.

## 1. Open the Project Folder

From PowerShell:

```powershell
cd "C:\Users\kamar\OneDrive\Documents\Projects\Garmin"
```

## 2. Create and Activate a Virtual Environment

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, run this once in the same terminal:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

## 3. Install Dependencies

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## 4. Configure `.env`

Create or update a `.env` file in the project root.

Required for Garmin sync:

```env
GARMIN_EMAIL=your_garmin_email@example.com
GARMIN_PASSWORD=your_garmin_password
```

Optional for AI insights:

```env
AI_PROVIDER=openai
OPENAI_API_KEY=your_openai_key
OPENAI_MODEL=gpt-5.5
```

Or, to use Anthropic:

```env
AI_PROVIDER=anthropic
ANTHROPIC_API_KEY=your_anthropic_key
ANTHROPIC_MODEL=claude-opus-4-8
```

Optional local paths:

```env
GARMIN_TOKENSTORE=.garmin_tokens
GARMIN_DB_PATH=data/garmin.db
```

Keep `.env` private. It contains secrets and should not be committed.

## 5. Sync Garmin Data

You can sync from the command line:

```powershell
python cli.py sync --days 30
```

For Garmin MFA, enter the code when prompted.

You can also sync from the app sidebar after launching the dashboard.

## 6. Launch the Dashboard

```powershell
streamlit run app.py
```

Streamlit will print a local URL, usually:

```text
http://localhost:8501
```

Open that URL in your browser.

## Common Commands

Sync the last 7 days:

```powershell
python cli.py sync
```

Sync the last 90 days:

```powershell
python cli.py sync --days 90
```

Start the dashboard:

```powershell
streamlit run app.py
```

Stop the dashboard:

```text
Press Ctrl+C in the terminal running Streamlit.
```

## Generated Local Files

The app creates these local files/folders:

```text
.garmin_tokens/
data/garmin.db
```

These are ignored by git and can be regenerated by syncing again.

## Troubleshooting

If `streamlit` is not recognized, make sure the virtual environment is active and dependencies are installed:

```powershell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

If the dashboard says there is no data, sync first:

```powershell
python cli.py sync --days 30
```

If Garmin login fails, check `GARMIN_EMAIL`, `GARMIN_PASSWORD`, and any MFA prompt.

If AI insights are disabled, check `AI_PROVIDER` and the matching API key in `.env`.
